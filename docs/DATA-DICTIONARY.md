# 客流观测与区间

区域人数与两两交集必须是非负整数，单位人或千人。东门、中庭、西门映射为A、B、C。时间先转UTC后形成小时桶；非整点观测向下归入所在UTC小时桶。同一观测按version选择最高版，矛盾同版隔离。

最多三个区域。两区域无交集观测时联合人数为[max(A,B),A+B]；已知交集I时为A+B-I。三区域需要全部两两交集。三方交集T下界为max(0,AB+AC-A,AB+BC-B,AC+BC-C)，上界为min(AB,AC,BC)。联合人数为A+B+C-AB-AC-BC+T。区间无可行整数时整桶隔离。输出上下界，不估算未经观测的精确人数。日汇总是分桶客次的上下界相加，不宣称是全天独立人数。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。运行幂等键由输入字节、参数与规则版本计算。

三方交集仅在A、B、C三个区域齐全时适用，类型triple的left必须为ABC，right必须为空。

支持区域固定为A、B、C；其他区域标识拒绝，防止三方ABC记录关联到另一组区域。

## 改造期分区归属（东门分段）

商场改造把东门（A）拆成两段 A1、A2，扶梯口是两段仍重叠的区域。改造期不得沿用旧东门整区口径（会掩盖重叠段），也不得把两段直接相加（扶梯口被算两遍）。分区归属以 `zone_parts` 登记为唯一口径来源，状态为 pending / confirmed / merged，并带 UTC 有效窗口；区间页面（`/renovation`）与归档证据（`/api/renovation/versions/<v>/export.csv`）读取同一份发布快照中的冻结归属，不分叉。

- 同一父区下两段均 confirmed：观测到扶梯口交集 I 时联合人数为 A1+A2-I（精确）；未观测交集时只给保守区间 [max(A1,A2), A1+A2]，不伪造精确人数。重叠人数超出任一分段观测按 CONSTRAINT 隔离。
- 任一分段 pending：该时段分段观测只进入“待确认”证据（原因码 ATTRIBUTION_PENDING），不并入正式人数区间；其他区域仍可独立出区间。
- merged 或超出有效窗口：分段归属失效，恢复整区口径；残留的 A1/A2 观测按 UNMAPPED_PART 隔离，不会被悄悄相加。
- 分段观测缺失按 REFERENCE 隔离，不补零、不估算。
- 跨父区在无交集观测时按 [max, sum] 保守联合，与既有两区域口径一致。

补传边界记录（扶梯口 pair 等）按内容哈希幂等暂存：重跑同一记录不新增暂存、不产生新版本。发布只重算受影响小时桶，未触及时段沿用上一版快照（kept_buckets），汇总按当前快照独立求和。发布是单一显式事务，带 expected_version 乐观条件：版本不匹配返回 409，事务内任何失败整体回滚、旧版保留；边界引用未登记分区按 REFERENCE 拒绝。
